# User Stories

## Investigator

- As an on-call engineer, I want one-click seeded evidence so I can evaluate the product without setup.
- As an SRE, I want the system to connect deployment, code, and log timing so I can test a causal hypothesis.
- As a technical lead, I want cited claims and contradictions so I can judge uncertainty.
- As a release engineer, I want to inspect the precise changed file and commit metadata.
- As a responder, I want to see corrective search steps so the conclusion is auditable.

## Evaluator

- As a recruiter, I want a calm guided experience that demonstrates engineering depth within minutes.
- As a reviewer, I want reproducible benchmark outputs rather than marketing claims.
- As a security reviewer, I want clear trust boundaries and tests for traversal, injection, size, CORS, and secret exposure.

## Operational stories

- As a developer, I want one documented setup path and deterministic tests without paid services.
- As a maintainer, I want provider and storage abstractions so a production backend can replace the local defaults.
- As an operator, I want request IDs and stage timings to investigate failures without logging sensitive content.
